# AGENTS.md

This repository is a small travel-content site and documentation project for tours in Dien Bien Phu and Laos.

## Project purpose
- Keep the public-facing travel storytelling coherent, respectful, and easy to follow.
- Maintain docs, pages, and collection content in a consistent style.
- Prefer simple, focused edits over broad rewrites.

## Working expectations
- Read the relevant files before editing. Prefer targeted changes over large refactors.
- Preserve the existing markdown structure, clickable links, and page organization.
- Do not invent unsupported travel details, prices, dates, routes, or stories.
- When editing content, match the repository’s tone: clear, inviting, and grounded in the project’s mission.
- Keep changes easy to review and easy to maintain.

## Key files to review
- README.md
- docs/index.md
- docs/_tours/*.md
- docs/script.js
- docs/styles.css

## Preferred workflow for AI agents
1. Inspect the exact file and neighboring examples.
2. Make the smallest necessary edit.
3. Keep formatting consistent with the existing markdown.
4. Summarize what changed and note any assumptions.

## Do not
- Add speculative facts not present in the repository.
- Reformat unrelated files.
- Remove or break existing links, navigation, or site assets.
- Expand the scope beyond the task the user asked for.
